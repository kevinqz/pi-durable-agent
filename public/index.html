Session recovery

          

            Keep a checkpoint of this conversation, its memory and pending
            approvals. Restoring keeps completed notes and recorded model usage.
          

          

          
          

          
          
          
          

          

          

          

          

            What this protects
            

              Checkpoints are stored with this session in Cloudflare, including
              its executor state. They protect against changes to the
              conversation; they are not downloadable backups or protection
              against deletion of the whole session, namespace or account. Up to
              three checkpoints are retained, with no automatic deletion.
            

          

        

        

          
Keep a copy

          

            Download the full retained message history, current memory view and
            action records as JSON. The file contains private data and is not
            encrypted. It is for reading and inspection; it cannot restore a
            running session or authorize an action.
          

          
          

        

        

          

            Session diagnostics
            

            

            

            

              Restart only this demo session's process. Saved messages and
              approvals stay in storage. Wait for active work to finish first.
              This tests a process reset, not backup or disaster recovery.
            

            
          

        

      

    

    
      
Restore this checkpoint?

      

      

        The conversation, memory and approvals will return to this saved point.
        Later notes and consumed model calls remain recorded. The current copy
        is retained for operator recovery.
      

      

        Pending actions still require a current approval. Other open tabs must
        refresh before sending messages or approving actions.
